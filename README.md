# Атлас мозга · Brain Atlas

Интерактивный конспект по нейронауке на русском и английском: от одного нейрона до целого мозга.

**Сайт:** https://lm004yky.github.io/neuro-atlas/

## Структура курса

| Уровень | Темы |
| --- | --- |
| Клетка | Нейрон и импульс, Синапс, Глия (скоро) |
| Системы | Слух, Равновесие, Зрение, Осязание и боль, Движение, Память, Эмоции, Сон (скоро) |
| Мозг целиком | Карта мозга |

Каждая тема устроена одинаково:

1. **Идея за 30 секунд** — одна мысль и аналогия.
2. **Потрогай** — интерактивы.
3. **Как это в мозге** — путь сигнала по шагам.
4. **Если сломалось** — болезни и поражения.
5. **Проверь себя** — три вопроса. После ответа на все тема отмечается пройденной.

## Как добавить тему

1. Скопируйте `js/topics/vestibular.js` в новый файл, например `js/topics/vision.js`.
2. Поменяйте `id`, `level` (`cell`, `systems` или `brain`) и тексты. Любой текст пишется парой `["русский", "English"]`.
3. Подключите файл в `index.html` рядом с остальными темами.
4. Если тема была в `js/topics/soon.js`, удалите её оттуда.

## Запуск

Сборка и сервер не нужны: откройте `index.html` в браузере.

## Файлы

- `index.html` — каркас и подключение тем
- `css/style.css` — стили и палитра
- `js/core.js` — язык, звук, хелперы, реестр тем
- `js/app.js` — главная, шаблон темы, путь сигнала, тесты
- `js/topics/*.js` — по файлу на тему
